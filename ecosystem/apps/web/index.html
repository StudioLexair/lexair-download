ANTES DE EMPEZAR

Preguntas frecuentes.

¿Qué puedo descargar?

La nueva versión todavía no descarga contenido. Se prevén adaptadores para fuentes compatibles, respetando permisos y restricciones.

¿Cómo instalo la aplicación?

La nueva versión todavía no está publicada. El botón mostrará un aviso hasta que exista un paquete disponible.

¿Puedo elegir MP3 o ver vídeos dentro de la app?

La conversión de audio y la vista previa integrada están pendientes de implementación.

¿Funciona con cualquier navegador o contenido protegido?

La integración con navegadores está en planificación y aún no se incluye en la nueva foundation. Lexair no eliminará DRM ni evitará restricciones de acceso.

EMPIEZA CON LEXAIR

¿Listo para empezar?

La nueva versión para Windows está en desarrollo; aún no hay un paquete publicado.
