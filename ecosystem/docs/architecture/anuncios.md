# StudioLexair Ads · integración experimental

Slug confirmado por el script central para `/lexairdownload`: `lexairdownload`. Web: `apps/web/index.html` incluye una sola vez el script oficial no bloqueante. La fuente de la ruta pública integrada está en el repositorio `studiolexair-routing/lexairdownload/index.html`; CSP y bypass SW correspondientes están en su `public/_headers` y `public/sw.js`. Las fuentes de los dos repositorios deben integrarse con sus ramas actuales antes de despliegue. No se modificó ni publicó el script central.

Flutter: solo la pantalla de inicio monta el host; no hay anuncios en búsqueda activa (se ocultan al enfocar un campo), formularios, cola, descargas u otras pantallas. Se consulta el feed público con `project=lexairdownload`, un UUID v4 persistente y `path=/`; sin JWT ni claves. URLs multimedia deben ser HTTPS y enlaces de destino HTTPS o relativos al dominio oficial. Se admiten imagen/GIF y vídeo silenciado, un flotante y un inline. Los anuncios respetan retardo, límites de sesión, exclusiones, cierre, cooldown y preferencias persistentes. Las impresiones/clics se guardan en outbox local y se reintentan cuando hay red; no se garantiza entrega ante fallo de disco o cierre antes de persistir el evento. Los errores de red no bloquean la aplicación.

## Límites y privacidad
- El `visitor_id` se guarda de forma independiente en la base Flutter y en localStorage del navegador. No se puede garantizar que representen al mismo usuario entre aplicaciones, instalaciones o dispositivos. La deduplicación entre proyectos depende de la función del servidor y no se verificó de extremo a extremo.
- La aplicación persiste `seen_<id>`, `clicked_<id>` y `dismissed_<id>` y el outbox en SQLite. Las rutas y datos están sujetos a la protección del sistema operativo. No hay interfaz de consentimiento/opt-out ni política de privacidad específica; antes de publicar, revisar requisitos legales y opciones de usuario.
- Los hosts multimedia son URLs HTTPS suministradas por el feed. Se validan las URLs iniciales; no se ha auditado cómo la pila nativa de imágenes/mpv maneja las redirecciones posteriores. No ejecutar en producción sin revisar redirecciones, acceso a red y binarios multimedia.
- El script real publicado hoy responde con `Cross-Origin-Resource-Policy: same-origin`. La propuesta del repo web incorpora una excepción `cross-origin` solo para `/ads.js`, necesaria si se usa desde un origen distinto. No estará activa hasta el despliegue autorizado. En la URL oficial `/lexairdownload/` el script es del mismo origen.
- Sin pruebas con anuncios reales de producción ni POST reales para no contaminar métricas. Las pruebas de API usan cliente simulado; la prueba web usa el script oficial recuperado y feed/POST simulados, sin red de producción para eventos. No se ha ejecutado la UI o vídeo de anuncios en Windows.
