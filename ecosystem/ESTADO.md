# Estado experimental (17 de noviembre de 2026)

Esta rama contiene un prototipo, no una versión para distribución pública. La interfaz de búsqueda y tendencias no tiene fuentes reales conectadas. La interfaz incorpora una conexión experimental a descargas HTTP directas y la cola; enlaces de plataformas no son descargables desde esta interfaz. Reproductor local desarrollado con media_kit: reproducción, códecs y licencias de binarios deben verificarse en Windows. No se garantiza compatibilidad absoluta.

La CI compila y prueba un artefacto experimental; no crea GitHub Releases ni publica la web, y no significa aprobación de seguridad. Motor y cola requieren pruebas de red pública, pruebas de cortes durante escritura, publicación segura, limpieza de temporales y revisión de seguridad. El ZIP no se enlaza desde la web. Conserva la versión 1.1.0 anterior separada y no reactiva GitHub Pages.
